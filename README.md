# Tic-tac-toe

## Instructions

To play a game, a pair of clients and a running server are needed. Below are
some example commands to start them.

```sh
$ go run cmd/server/main.go
$ go run cmd/client/main.go
```

The binaries can be built with the following commands.

```sh
$ go build -o client cmd/client/main.go
$ go build -o server cmd/server/main.go
```
